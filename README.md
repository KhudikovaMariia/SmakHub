# SmakHub

SmakHub — сайт-книга рецептів, де можна швидко знайти страву за назвою, категорією або інгредієнтами, які є вдома, зберігати улюблені рецепти та додавати власні.

Навчальний проєкт з дисципліни «Веб-орієнтована розробка програмного забезпечення»
(КПІ ім. Ігоря Сікорського, ННІ прикладного системного аналізу).

## Робота з шаблоном

Кожна сторінка використовує однакові `<header>`, `<nav>` і `<footer>`.
Для нової сторінки скопіюйте `template.html`, додайте її посилання в меню та футер усіх сторінок
і позначте `aria-current="page"` пункт поточної сторінки.

## Доступність

- семантичні елементи `header`, `nav`, `main`, `footer`, `section`, `article`;
- посилання «Перейти до вмісту», видимий фокус, `aria-current` у меню;
- усі поля форм мають `label`, змістовні зображення — `alt`;
- контраст тексту, посилань і кнопок відповідає WCAG AA (≥ 4.5:1).

## Робота з Git

- Кожен учасник працює у власній гілці (`feature/<назва>`) і зливає її через Pull Request.
- Формат комітів: `тип: короткий опис`, наприклад `feat: додано форму фільтрів у каталозі`,
  `fix: виправлено контраст кнопок`, `docs: оновлено README`.
