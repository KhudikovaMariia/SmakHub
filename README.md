# SmakHub

SmakHub — сайт-книга рецептів, де можна швидко знайти страву за назвою, категорією або інгредієнтами, які є вдома, зберігати улюблені рецепти та додавати власні.

Навчальний проєкт з дисципліни «Веб-орієнтована розробка програмного забезпечення»
(КПІ ім. Ігоря Сікорського, ННІ прикладного системного аналізу).

## Структура проєкту

```
smakhub/
├── images/          # зображення (оптимізовані)
├── css/
│   └── style.css    # спільні стилі за брендбуком
├── js/
│   └── main.js      # спільний скрипт (мобільне меню)
├── index.html       # головна
├── catalog.html     # каталог рецептів
├── recipe.html      # сторінка рецепта
├── login.html       # вхід
├── register.html    # реєстрація
├── about.html       # про нас
├── contacts.html    # контакти
├── 404.html         # сторінка помилки
├── template.html    # порожній шаблон для нових сторінок
└── README.md
```

## Робота з шаблоном

Кожна сторінка використовує однакові `<header>`, `<nav>` і `<footer>`.
Для нової сторінки скопіюйте `template.html` і додайте `aria-current="page"` до її пункту в меню.
